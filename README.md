# 🔍 Word Frequency Counter

A simple Python project that analyzes user-provided text and counts the frequency of each word.

## 📌 Features

- Accepts text input from the user.
- Splits text into individual words using `.split()`.
- Uses a dictionary to store word frequencies.
- Uses loops and conditional statements to count occurrences.
- Displays each word alongside its frequency.

## 🛠️ Concepts Practiced

- Python Strings
- String `.split()` Method
- Dictionaries
- `for` Loops
- `if-else` Statements
- Dictionary Methods (`.items()`)

## 💻 Example

**Input:**
```text
Python is easy and Python is powerful
```

**Output:**
```text
Word Frequency:
Python: 2
is: 2
easy: 1
and: 1
powerful: 1
```

## ▶️ How to Run

